# Nova Agency – Custom WordPress Theme

Nova Agency is a custom WordPress business website theme built from scratch as a portfolio project.

The project demonstrates custom WordPress theme development using PHP, Advanced Custom Fields (ACF), Custom Post Types, WordPress Template Hierarchy, responsive CSS, and JavaScript.

## Features

- Custom WordPress theme built from scratch
- Responsive design for desktop, tablet, and mobile
- Dynamic homepage content using Advanced Custom Fields (ACF)
- Custom Projects post type
- Projects archive and individual project pages
- Featured images for projects
- Dynamic WordPress navigation menus
- Custom logo support
- Mobile navigation menu
- Back-to-top functionality
- Reusable WordPress templates
- Responsive layouts using CSS Grid and Flexbox

## Technologies Used

- WordPress

The theme uses several core WordPress development concepts, including:

## Homepage Sections

The homepage includes:

- Hero
- Services
- About
- Projects
- Call to Action

Homepage content is managed dynamically through ACF fields in the WordPress admin area.

## Projects

Projects are managed through a custom `project` post type.

The theme includes:

- A projects archive page
- Individual project pages
- Featured images
- Project titles and content
- Dynamic project display on the homepage using `WP_Query`

## Responsive Design

The website is responsive and adapts its layout for smaller screens.

Responsive functionality includes:

- Mobile navigation
- Single-column content layouts
- Responsive project cards
- Responsive typography and spacing
- Flexible images
